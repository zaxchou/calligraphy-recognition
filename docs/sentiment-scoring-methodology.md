## 1. 概述

本系统对中国古代书画题跋进行多维度情感分析，输出 [-1, +1] 范围的归一化情感分数。

### 核心创新

1. **三维度融合**：文字 + 空间布局 + 印章，而非仅依赖文本
2. **VADER 归一化**：使用学术界成熟的归一化公式
3. **置信度加权**：无数据的维度自动降权
4. **LLM 校准**：用 DeepSeek 作为参考标准，优化权重

## 3. 情感词典 (emotion_lexicon.json)

### 3.1 构建方法

1. **候选词提取**: 从 `tibi_analysis_rules.py` 中提取 142 个情感词
2. **LLM 标注**: 用 DeepSeek v4-flash 对每个词在书画语境下打分 (-4 到 +4)
3. **人工修正**: 对 LLM 评分不准的词进行手动修正（如"臣非老画师"从 0 修正为 -3）
4. **去重处理**: 最长匹配优先，避免重复计数

### 3.2 词典统计

| 分类 | 数量 | 分数范围 |
|------|------|---------|
| negative_strong | 25 | -3 到 -4 |
| negative_moderate | 38 | -2 |
| negative_mild | 21 | -1 |
| neutral | 5 | 0 |
| positive_mild | 10 | +1 |
| positive_moderate | 21 | +2 |
| positive_strong | 22 | +3 到 +4 |

### 3.3 词典格式

{

  "method": "llm_rating",

## 4. 校准流程

### 4.1 校准数据

- 样本量: 30 幅作品（李鱓为主）
- 参考标准: DeepSeek v4-flash 情感分析
- 校准方法: 梯度下降优化权重

### 4.2 校准结果

| 指标 | 旧系统 | 新系统 |
|------|--------|--------|
| MAE | 0.556 | 0.052 |
| 改进幅度 | - | +90.6% |

### 4.3 校准后权重

| 维度 | 权重 |
|------|------|
| 文字 | 0.050 |
| 空间 | 0.569 |
| 印章 | 0.381 |

**说明**: 文字权重很低（0.050）是因为词典分数范围大（-4 到 +4），需要降低权重以平衡其他维度。

## 5. VADER 归一化

### 5.1 公式

```
compound = raw_score / √(raw_score² + α)
```

其中 α = 8.0（经测试，适合我们的分数范围）

### 5.2 特性

- **有界**: 输出永远在 [-1, +1]
- **单调递增**: 分数越高，输出越大
- **饱和效应**: 接近 ±1 时增长变慢
- **奇函数**: normalize(-x) = -normalize(x)

### 5.3 参考文献

> Hutto, C.J. & Gilbert, E. (2014). "VADER: A Parsimonious Rule-based Model for Sentiment Analysis of Social Media Text." *Proceedings of the International AAAI Conference on Web and Social Media (ICWSM).*

## 6. 空间情绪规则

基于张君飞《李鱓题画书法研究》论文框架。

| 布局类型 | 情绪 | 分数 |
|---------|------|------|
| 边角式 | neutral | 0.0 |
| 拦边封角式 | neutral_controlled | -0.3 |
| 化虚为实/填充式 | positive_resolved | +0.4 |
| 重力平衡式 | neutral_balanced | +0.1 |
| 穿插式 | positive_unrestrained | +0.8 |
| 侵入画位/喧宾夺主式 | negative_intense | -1.0 |
| 长篇排布/画材填空式 | negative_controlled | -0.5 |
| 从左起笔式 | neutral | 0.0 |

## 7. 印章情绪规则

基于李鱓印章研究，按类别加权：

| 类别 | 权重 | 说明 |
|------|------|------|

| life_experience | 0.7 | 人生经历间接反映 |

| identity | 0.3 | 身份标识情感弱 |
| hobby | 0.3 | 爱好情感弱 |
| location | 0.2 | 地点基本中性 |

## 8. 使用示例

### 8.1 Python 调用

```python
from app.services.scoring_engine import quick_score

result = quick_score(
    text_raw=-3.0,      # 文字情感分
    spatial_raw=-0.5,   # 空间情感分
    seal_raw=0.0,       # 印章情感分
)

print(f"综合分数: {result.combined_normalized:.3f}")
print(f"极性: {result.polarity}")
print(f"推理: {result.reasoning}")
```

### 8.2 输出示例

```
综合分数: -0.504
极性: negative
推理: 文字消极、空间消极、印章无数据，综合消极
```
