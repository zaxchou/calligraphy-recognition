# 墨林情绪引擎 (Molin Emotion Engine)

> 基于 VADER 框架，融合文言文情感计算与书画领域知识的独立情绪判断系统

---

## 一、系统定位

**核心价值**：将书画题跋的情感分析从"拍脑袋打分"升级为"有学术依据、可校准、可追溯"的研究工具。

**知识产权**：
- 通用文言文情感词典（LLM 标注 + 专家修正）
- 书画空间情绪量化模型（基于论文框架）
- 画家特化规则库（时期基线、印章、画材）
- 校准方法论（VADER 归一化 + LLM 参考标准）

**独立性**：引擎可独立部署，管理后台集成到现有系统。

## 三、七大维度详解

### 维度 1: 文字词典（通用）

**现状**: 151 词，LLM 标注
**目标**: 500+ 词，覆盖文言文核心情感词汇

**扩展策略**:
1. **古文情感词**: 从文言文语料中提取（悲、哀、凄、凉、愁、苦、闷、怒、愤、憾、恚、恼、叹、慨、惘、惆、寂、破、残、衰、败、倦、惊、恐、喜、笑、呵、乐、欢、欣、狂、放、纵、酣、畅、快、爱、慕、趣、兴、怡、娱、傲、雄、健、劲、凌）
2. **书画专用词**: 笔墨、气韵、写意、工细、纵横、恣肆、酣畅、游戏
3. **典故词**: 臣非老画师、两革科名、一贬官、老夫卖画
4. **反讽词**: 莫笑、堪笑、自笑、一笑、休笑、人笑、应笑、可笑

**标注方式**: DeepSeek 批量标注 + 人工修正关键词

**数据格式**:
```json
{
  "version": "2.0",
  "entries": {
    "悲": {"score": -3, "category": "negative_strong", "source": "llm_rated", "era": "通用"},
    "臣非老画师": {"score": -3, "category": "negative_strong", "source": "manual", "era": "李鱓专用"}
  }
}
```

### 维度 2: 空间布局（通用）

**现状**: 8 种布局类型，已有量化分数
**目标**: 保持现有，增加更多布局类型

**数据来源**: 张君飞《李鱓题画书法研究》论文框架

**分数范围**: -1.0 到 +0.8

**扩展方向**:
- 增加更多布局类型（如"通景屏式"、"册页连环式"）
- 增加留白比例×布局类型的交叉规则

### 维度 3: 画材情感（通用）

**现状**: 9 种画材类别
**目标**: 保持现有，按画家特化

**画材类别**:
| 画材 | 情感倾向 | 通用分数 |
|------|---------|---------|
| 傲骨/坚韧 | positive | +0.2 |
| 萧瑟/压抑 | negative | -0.5 |
| 富贵/长寿 | positive | +0.5 |
| 灵动/自在 | positive | +0.2 |
| 生活化/质朴 | neutral | 0.0 |
| 谐音吉祥 | positive | +0.5 |
| 高远/清幽 | positive | +0.1 |
| 繁茂/珠玉 | positive | +0.1 |
| 鲜活/自在 | positive | +0.1 |

### 维度 4: 尺寸元数据（通用）

**现状**: 3 种尺寸分类
**目标**: 保持现有

**尺寸分类**:
| 尺寸 | 高度范围 | 情感倾向 |
|------|---------|---------|
| 小幅 | <70cm | 随性、自娱 |
| 中幅 | 70-150cm | 标准、正式 |
| 大幅 | >150cm | 庄重、展示 |

### 维度 5: 时期基线（特化）

**现状**: 李鱓 3 个时期
**目标**: 每个画家都有自己的时期划分

**数据来源**: 画家百科 + 艺术史研究

**李鱓示例**:
| 时期 | 年份 | 情感基线 | 权重 |
|------|------|---------|------|
| 早期（入宫学蒋） | 1714-1722 | +0.3 | 1.0 |
| 中期（出京卖画） | 1723-1745 | -0.3 | 1.5 |
| 晚期（彻底归隐） | 1746-1760 | -0.5 | 2.0 |

### 维度 6: 印章情感（特化）

**现状**: 25 枚印章，6 个类别
**目标**: 随画家增加而扩展

**印章类别权重**:

## 四、管理后台设计

### 4.1 词典管理

**页面**: `/admin/emotion-engine`

**功能**:
- 查看/编辑情感词典
- 按类别筛选（negative_strong, positive_mild 等）
- 按来源筛选（llm_rated, manual）
- 批量导入/导出
- 版本历史

**字段**:
| 字段 | 类型 | 说明 |
|------|------|------|
| word | string | 词语 |
| score | int | 情感分数 (-4 到 +4) |
| category | enum | 分类 |
| source | enum | 来源 |
| note | string | 备注 |
| era | string | 适用时代（通用/李鱓专用等） |

### 4.2 画家规则管理

**页面**: `/admin/emotion-engine/artist/{artist_id}`

**功能**:
- 管理画家时期基线
- 管理画家印章库
- 管理画家画材偏好
- 查看校准结果

### 4.3 校准工具

**页面**: `/admin/emotion-engine/calibration`

**功能**:
- 选择样本（按画家/时期/主题）
- 运行 LLM 参考评分
- 对比系统输出 vs LLM 参考
- 自动优化权重
- 导出校准报告

## 五、数据流

```
题跋文本
    │
    ├─→ 文字词典匹配 → text_raw
    │
    ├─→ 空间布局分析 → spatial_raw
    │
    ├─→ 画材匹配 → painting_raw
    │
    ├─→ 尺寸分析 → size_raw
    │
    ├─→ 时期基线 → period_raw (特化)
    │
    ├─→ 印章分析 → seal_raw (特化)
    │
    └─→ 主题分类 → theme_raw (特化)
            │
            ▼
    ┌───────────────────────────────┐
    │  加权融合                      │
    │  S_raw = Σ(wᵢ × cᵢ × sᵢ)    │
    │                               │
    │  通用维度:                     │
    │    text: w=0.40               │
    │    spatial: w=0.20            │
    │    painting: w=0.10           │
    │    size: w=0.05               │
    │                               │
    │  特化维度:                     │
    │    period: w=0.10             │
    │    seal: w=0.10               │
    │    theme: w=0.05              │
    └───────────────┬───────────────┘
                    │
                    ▼
    ┌───────────────────────────────┐
    │  VADER 归一化                  │
    │  S = S_raw / √(S_raw² + α)   │
    │  α = 8.0                      │
    │  输出: [-1, +1]               │
    └───────────────────────────────┘
```

## 六、校准方法

### 6.1 校准流程

1. **样本选择**: 从数据库随机抽取 50 幅作品（覆盖不同画家、时期、主题）
2. **LLM 参考**: 用 DeepSeek 对每幅作品做情感分析（polarity + intensity）
3. **系统输出**: 用当前引擎对同一批作品做情感分析
4. **权重优化**: 梯度下降，最小化系统输出 vs LLM 参考的 MAE
5. **验证**: 用另外 20 幅作品做验证集

### 6.2 校准指标

| 指标 | 说明 | 目标 |
|------|------|------|
| MAE | 平均绝对误差 | < 0.10 |
| 相关系数 | Pearson r | > 0.80 |
| 极性准确率 | positive/negative/neutral 分类准确率 | > 85% |

### 6.3 校准频率

- 新增画家时：校准该画家的特化权重
- 词典更新时：重新校准通用权重
- 每季度：全量校准一次

2. Phase 2 重构引擎，支持多画家校准
