## 产品目标

基于现有书法题跋分析系统，叠加「李鱓题跋内容学术分析」功能模块，服务于论文写作中的量化论证。

## 核心功能

### 第一阶段：数据基础（题跋文本 LLM 提取与校对）

**数据摸底与清洗**

- 从 `tubi_analyses` 表导出全部 48 条记录（含李鱓46条、郑燮2条需排除）
- 现有 `inscription_content` 字段质量参差（2-200字），需要逐条核验
- 现有 `period` 字段存储"年龄"（如"41岁"、"66岁"），需重建为李鱓三期：`早期(1718前)` / `中期(1718-1744)` / `晚期(1744后)`
- `year` 字段：1727-1760 均有分布，按分期规则重建 period

**李鱓题跋特征词库（词频追踪用）**

共6个维度、100+词条，作为词频分析的核心追踪目标：

| 维度 | 特征词 | 分析目的 |
| --- | --- | --- |
| **核心艺术理念** | 水、墨、笔、色、气、韵、娱、戏、乐、寄、自怡、门户、法、师、我法 | 追踪"用水论"、"以画为娱"、师承创新等核心主张的演变 |
| **情感与心境** | 狂、放、纵、恣、酣、畅、悲、凄、凉、愁、叹、憾、傲、倔、不羁、喜、笑 | 量化情感强度变化，验证"中期激愤、晚期释然"假设 |
| **题材与物象** | 四君子（松、竹、梅、兰、菊）；蔬果（葱、姜、蒜、白菜、萝卜）；吉祥寓意（牡丹、萱草、芙蓉）；草虫鳞介（鹅、鸡、鸟、鱼、蟹、蝶）；农家器物 | **"以俗为雅"核心特征**，分五个子类追踪各期偏好变化 |
| **社会与民生** | 民、农、耕、田、粮、租、吏、官、衙、权、贵、霸、世、俗、尘、市、贾、金 | 验证"中期讽喻类题跋集中在社会批判"的假设 |
| **时空与创作** | 春、夏、秋、冬、晴、雨、风、雪、晨、午、夜、今、昔、年、岁、扬州、兴化、山东 | 关联人生轨迹与创作环境 |
| **哲学与审美** | 道、自然、天趣、真、朴、淡、空、静、虚、灵、禅、雅、俗、赏、鉴、味 | 追踪审美境界的演变 |


统计时对情感词做正负赋值（狂/悲/凄/凉/愁/叹/憾→负，娱/戏/乐/喜/笑/酣/畅→正）。

> **"傲"字的特殊处理**：需结合上下文判断——
> - 关联"松/竹/梅/兰"等君子意象 → **正向（傲骨）**
> - 描述创作状态或个人性格时 → **需 LLM 结合语境判定**
> - prompt 设计时要求模型输出具体理由，不做固定正负

**LLM 题跋提取流水线**

- 调用 Qwen VL Plus（复用现有 `qwen_vl_ocr_router.py` 三路机制）逐一重提取题跋文本
- 每条题跋同时产出：① 清洗后文本，② 主题分类结果，③ 情感极性，④ 文本长度统计
- 输出结构化 JSON 落库（新增字段，见下）

**新增数据库字段**（在 `tubi_analyses` 表新增列）

- `content_analysis`（JSON）：主题标签、情感极性、置信度、LLM原始推理
- `period_phase`（VARCHAR）：早期/中期/晚期（从 year 自动推导）
- `char_count`（INTEGER）：题跋字符数（不含标点）
- `word_count`（INTEGER）：题跋词数（jieba分词）
- `theme_tags`（VARCHAR）：逗号分隔的主题标签列表

**用户校对界面**

- 简单 Web 页面，逐一展示：图片缩略图 + LLM提取文本 + 当前数据库文本
- 用户可编辑确认，或跳过
- 校对完成后自动生成带标注的"干净语料库"

**前端注解体系（全链路可理解性）**

每个分析维度需附带解释性标注，使非技术用户（文史研究者）能理解数据含义：

| 注解位置 | 内容 |
| --- | --- |
| 术语 Tooltip | 悬停显示：如"侵入式布局"、"TTR词汇多样性"、"卡方检验显著性"等术语的解释 |
| 特征词维度说明 | 每维度卡片配解释：如"蔬果/农家器物→以俗为雅" |
| 主题分类说明 | 五大主题各有定义卡片 + 代表性题跋举例 |
| 统计结果注释 | 图表下方注明：样本数N、显著性标注含义（*p<0.05 **p<0.01） |
| 报告辅助解读 | 报告页提供"数据解读指南"：每个表格/图表的学术含义说明 |


注解内容在代码中以 JSON 配置存储，便于后续扩充。

### 第二阶段：分期量化统计

**文本基础统计**

- 各期（早期/中期/晚期）题跋数量、平均/最大/最小字符数
- 各期词汇多样性指数（TTR = Type-Token Ratio）
- 重点追踪特征词频率：`狂`、`悲`、`水`、`墨`、`娱`、`民`、`吏`、`官`、`米`、`花`、`竹`、`卖画`

**主题分类统计**

- 五大类主题（记录创作信息 / 即景寄兴抒怀 / 讽喻社会民生 / 阐述画理画法 / 世俗祈愿谐趣）
- 各期各类主题占比变化（堆叠柱状图数据源）
- 分类采用 Qwen VL Plus Zero-shot，允许多标签，每条输出置信度

**情感分析统计**

- 每条题跋：积极/消极/中性 + 强度（0-1）
- 各期情感极性分布（饼图 / 折线图）
- 验证假设：中期讽喻类题跋情感更消极

### 第三阶段：内容-形式关联分析

**数据基础**

- 形式数据：已有 `position_analysis` JSON（8种形式类型 matched 字段）+ `inscription_percent`
- 内容数据：五大主题分类结果
- **重点关注：侵入式布局（侵入画位 / 喧宾夺主式）**——这是李鱓题跋的标志性形式特征

**交叉统计**

- **主题 × 侵入式布局 专项分析**：统计讽喻类/抒怀类/世俗类题跋分别与"侵入画位"、"喧宾夺主式"搭配的频次
- 主题 × 形式 完整交叉列联表（8种形式 × 5种主题）
- 卡方检验验证显著性（p<0.05 标注"\*"，p<0.01 标注"\*\*"）
- 量化指标：共现强度（支持度 / 置信度）
- **验证假设**：内容激昂（讽喻/抒怀）→ 侵入式布局；内容淡雅（即景小趣）→ 边角规整式

### 第四阶段：论文报告输出

- LaTeX-ready 统计表格：可直接复制进论文
- Markdown 格式报告：包含文字解读 + 图表数据
- 支持导出：CSV（原始数据）+ Markdown（分析报告）

## 关键实现细节

### LLM 分类 Prompt 设计（Zero-shot）

每条题跋送 Qwen VL Plus，传入：图片 + 题跋文本 + 五大类定义，输出 JSON：

```
{
  "themes": [{"code": 3, "name": "讽喻社会民生", "confidence": 0.85}],
  "sentiment": {"polarity": "negative", "intensity": 0.72},
  "sentiment_reasoning": "通过'官吏'、'民'等词...",
  "char_count": 86,
  "objects_mentioned": ["葱", "姜", "官"],
  "reasoning": "通过'官吏'、'民'等词判定为讽喻类..."
}
```

- `objects_mentioned`：额外识别题跋中出现的具体物象词（葱/姜/蒜/鹅/鸡/水仙/芭蕉等），
用于"以俗为雅"子类词频统计
- `傲` 字由 LLM 结合语境判定正负，不做固定赋值，理由写入 `sentiment_reasoning`

### 分期规则（已确认，1718/1744 为节点）

```python
def get_period_phase(year: int) -> str:
    """
    早期: year < 1718（康熙朝，供奉内廷，工致严谨）
    中期: 1718 <= year < 1744（江湖卖画+短暂出仕，破笔泼墨）
    晚期: year >= 1744（乾隆朝，辞官归里，衰年变法）
    边界规则：year==1718 → 中期（乞归当年，画风已变）
             year==1744 → 晚期（返扬，晚年风格开启）
    """
    if year < 1718:
        return "早期"
    elif year < 1744:
        return "中期"
    else:
        return "晚期"
```

> **注意**：原 tibacontents.md 草拟分期（早期≤1723/中期1724-1740）与学术研究不符，
> 已更正为 1718（乞归）/ 1744（返扬）两个关键节点。
> 乾隆五年（1740）罢官后仍游走江湖至1744返扬，这6年归属中期。

### 校对保护机制

每条记录新增两个字段：

- `inscription_verified`（BOOLEAN，默认 false）：用户是否已校对确认
- `inscription_verified_at`（DATETIME）：校对时间戳

规则：只有 `inscription_verified = false` 的记录才会被 LLM 重提分析覆盖；
已校对记录需用户主动"重新校对"才可更新。

### 新图片批量导入（文件名解析 + 人工补充）

1. 扫描 `.jpg/.png/.jpeg/.tif` 图片
2. **文件名解析**（规则：`{时代}_{artist}_{title}_{year}.jpg`，如 `清_李鱓_松菊图_1727.jpg`），
解析出 artist/title/year 填充元数据；无法解析的字段留给用户补充
3. 用户在前端填写 / 修正 artist、title、year（如有落款年份可从题跋OCR提取参考）
4. 调用 OCR 三路机制提取题跋，创建 tubi_analyses 记录
5. `period_phase` 在 year 确定后由系统自动计算
6. 不覆盖已校对记录

### 内容-形式关联（卡方检验）

```python
from scipy.stats import chi2_contingency
table = [[count_讽喻_侵入], [count_讽喻_非侵入], ...]
chi2, p, dof, expected = chi2_contingency(table)
# p < 0.05 → 标注 "*"，p < 0.01 → "**"
```
