## 产品概述

在 ContentAnalysis.vue 大数据分析页面新增"主题·情感·分期三维关系网络图"，用可视化的方式展示李鱓题跋数据的内在关系。

## 核心功能

- 力导向网络图展示主题、情感、分期的三维共现关系
- 节点类型：主题节点（5个）+ 情感节点（3个）
- 连线粗细表示共现强度（有多少幅作品同时满足该组合）
- 节点颜色编码分期（早期/中期/晚期）
- 鼠标悬停显示详细共现数量和作品示例

## 技术栈

- 前端框架：Vue 3 + TypeScript
- 图表库：ECharts 5.6.0（已存在）
- UI 组件：Element Plus

## 技术方案

### 数据来源

- 后端新增 API：`/content-analysis/network-graph` 返回细粒度作品数据（每幅作品的主题、情感、分期）
- 或者复用现有数据在前端计算共现矩阵

### 数据结构

```typescript
interface NetworkGraphData {
  nodes: Array&lt;{
    id: string
    name: string
    category: 'theme' | 'sentiment'
    period?: string
    value: number
    symbolSize: number
  }&gt;
  links: Array&lt;{
    source: string
    target: string
    value: number
    lineStyle: { width: number }
  }&gt;
}
```

### ECharts 配置

- 使用 `graph` 类型，力导向布局（force）
- `force.repulsion` 控制节点排斥力
- `edgeSymbol` 和 `lineStyle` 控制连线样式
- `tooltip` 显示详细信息

## 实施要点

- 复用现有 ECharts 初始化模式（参考 `renderCharts()`）
- 在 `statsData` 基础上计算共现矩阵，或新增后端 API
- 图表容器高度设为 500px，与现有图表风格一致

## 页面布局

在 ContentAnalysis.vue 现有图表区域上方新增一个独立的力导向网络图卡片，位于"AI 数据洞察"下方、"术语说明"上方。

## 视觉风格

- 卡片采用与现有 el-card 一致的样式
- 节点配色延续现有主题配色（个人情感：#d4a88b、寄情自然：#7ba67b、讽喻社会：#c96442、文人交往：#a65d3f、风俗画：#8a8070）
- 情感节点配色：积极=#5ec962、中性=#909399、消极=#f56c6c
- 背景采用渐变玻璃质感，契合现有 Claude 风格

## 交互设计

- 节点鼠标悬停高亮并放大
- 连线悬停高亮并显示 tooltip
- 支持缩放和平移拖拽
