## 需求分析

### 后端功能修复

- **问题**：选择"AI文本分析"选项后依然走的是标注图分析的路线，没有实现轻量化快速只出文本结果
- **目标**：
- AI文本模式（analyze_text_only）：跳过图像区域检测和OCR，直接调用AI进行快速点评概述
- AI标注图模式（analyze）：保持原有完整分析流程（区域检测+OCR+标注图）
- 直接入库模式（manual）：只录入不分析

### 前端设计优化

- **问题**：当前使用两次 ElMessageBox.confirm，用户体验不佳
- **目标**：改为 Claude 风格的卡片式选项弹窗
- **修复bug**：第2104行硬编码传'analyze'，需要改为 selectedMode

### 三个选项

1. **直接入库**：仅录入，后续手动标注
2. **AI文本分析**：轻量化快速点评概述（无标注图）
3. **AI标注图分析**：完整分析（含区域检测+OCR+标注图）

## 技术方案

### 后端修改

1. **siliconflow_service.py**：新增轻量化分析函数 `analyze_text_summary_only`

- 复用现有AI调用逻辑
- 简化prompt，只生成画作点评概述
- 不进行区域检测和OCR识别
- 返回格式：`{ success: boolean, analysis_note: string }`

2. **tubi_worker.py**：修改 `process_one` 函数

- 根据 `db_job.mode` 分支处理
- `mode="analyze"`：原有完整流程
- `mode="analyze_text_only"`：新轻量化流程
    - 跳过 `analyze_with_timeout`
    - 跳过OCR识别
    - 调用新的轻量化分析函数
    - 只保存 `analysis_note`，不保存区域数据、面积统计、标注图
- 设置 `db_analysis.status` 为 "analyzed"

### 前端修改

1. **TubiAnalysis.vue**：修复 bug 并重构弹窗

- 修复第2104行：`tubiApi.batchAutoAnalyze(uploadedIds, selectedMode)`
- 移除两次 ElMessageBox.confirm
- 新增 Claude 风格的选项弹窗
    - 三个卡片式选项在同一弹窗展示
    - Claire 风格设计：圆角、阴影、简洁排版
    - 清晰的图标和描述
    - 单步选择，提升用户体验

## 设计方案：Claude风格上传弹窗

### 设计风格

- **简洁现代**：Claude风格，大圆角、柔和阴影、清晰层次
- **卡片式选项**：三个选项在同一弹窗中以卡片形式并列展示
- **单步操作**：从两步确认改为单步选择，提升用户体验

### 弹窗布局

```
┌─────────────────────────────────────┐
│         选择处理方式                 │
├─────────────────────────────────────┤
│  ┌──────────┐  ┌──────────┐  ┌─────┐│
│  │  📁      │  │  📝      │  │ 🎨  ││
│  │直接入库  │  │AI文本分析│  │AI标 ││
│  │仅录入不  │  │快速点评概│  │注图  ││
│  │分析      │  │述        │  │分析  ││
│  └──────────┘  └──────────┘  └─────┘│
│                                     │
│         [取消]  [确认选择]         │
└─────────────────────────────────────┘
```

### 卡片设计细节

- 每个选项卡片包含：
- 图标（顶部居中）
- 标题（粗体）
- 描述（小字）
- Hover状态：边框高亮、轻微上浮

### 视觉风格

- **圆角**：12px 大圆角
- **阴影**：柔和的 drop-shadow
- **颜色**：主色调保持现有系统风格，卡片白色背景
- **交互**：点击选中时显示蓝色边框，Hover 时显示浅色背景
