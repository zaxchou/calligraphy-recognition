## 需求描述

统一解决 id 和 image_id 双 ID 混乱问题，确保系统稳定运行。

### 核心问题

1. 作品库点击失效：从作品库点击进入作品详情页无法正常跳转
2. 双 ID 混乱：后端和前端对 id 和 image_id 的使用不一致
3. 册页管理、尺寸录入、标签管理等模块使用不同 ID 标准

### 修复目标

- 统一使用 image_id (UUID) 作为外部唯一标识
- 修复所有模块的 ID 使用问题
- 确保作品库点击跳转正常工作

## 技术方案

### 统一策略

**统一使用 image_id (UUID) 作为外部唯一标识**

- 数据库：id (自增主键，仅内部使用) + image_id (UUID，外部唯一标识)
- 后端 API：统一返回格式 `{ id: image_id, db_id: id, image_id: image_id }`
- 前端：所有模块统一使用 image_id

### 修复范围

1. **后端 API**：确保所有接口返回格式一致
2. **前端模块**：

- TubiAnalysis.vue：作品库点击跳转
- AlbumManager.vue：册页管理
- DimensionInput.vue：尺寸录入
- TagManager.vue：标签管理

### 关键修复点

- loadHistoryItem() 函数确保正确处理 image_id
- 路由跳转使用 image_id
- 所有 API 调用统一使用 image_id
