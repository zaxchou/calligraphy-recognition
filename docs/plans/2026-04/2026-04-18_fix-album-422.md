## 问题描述

AlbumManager.vue 和 TagManager.vue 中，`<el-form>` 缺少 `@submit.prevent`，导致在输入框按 Enter 键时同时触发：

1. `@keyup.enter` 的 axios JSON POST（正确请求，Content-Type: application/json）
2. 原生 `<form>` 的 submit 事件（错误请求，Content-Type: form-urlencoded）

FastAPI 收到 form-urlencoded 格式的请求体后无法解析为 Pydantic 模型，返回 422 Unprocessable Content。

## 错误表现

浏览器控制台显示：

```
Failed to load resource: the server responded with a status of 422 (Unprocessable Content)
API Error: AxiosError: Request failed with status code 422
```

## 修复方案

给所有包含 `@keyup.enter` 的 `<el-form>` 添加 `@submit.prevent`，阻止原生表单提交事件。

## 涉及文件

- `frontend/src/views/AlbumManager.vue` — 1 处 `<el-form>` (line 96)
- `frontend/src/views/TagManager.vue` — 2 处 `<el-form>` (line 127, line 151)
