## 产品概述

为李鱓题跋大数据分析页面新增4个面积数据可视化图表，从多个维度展示题跋、绘画、留白三者的面积分配关系及其与其他维度的关联。

## 核心功能

1. **面积分布直方图** - 展示题跋/绘画/留白在不同面积区间的作品数量分布
2. **面积-主题堆叠柱状图** - 展示不同主题下三者的面积分配比例
3. **面积三元图** - 用三角形坐标系展示每幅作品在三者之间的平衡关系
4. **面积-尺寸相关性分析** - 散点图展示作品物理尺寸与题跋面积占比的关系

## 技术方案

### 技术栈选择

- 前端：Vue 3 + TypeScript + ECharts + Element Plus
- 后端：FastAPI + SQLite
- 图表库：ECharts（项目已在用，无需新增依赖）

### 实现方案

1. **后端API扩展**：在 `/content-analysis/stats` 响应中新增面积相关字段，或新增 `/content-analysis/area-stats` 端点
2. **前端图表实现**：复用现有的 ECharts 渲染模式，在 ContentAnalysis.vue 中新增4个图表组件
3. **数据结构设计**：返回作品级别的细粒度数据，支持多维度聚合

### 关键设计决策

- 复用现有 `/content-analysis/stats` 端点扩展字段，避免新增API
- 使用 ECharts 的 scatter、bar、custom 系列实现四种图表
- 确保向后兼容，不破坏现有功能

### 数据流程

```
数据库查询 → 后端聚合计算 → API返回 → 前端ECharts渲染
```

## 设计风格

延续现有 ContentAnalysis.vue 的 Claude 风格设计：大圆角卡片、柔和阴影、清晰的视觉层次、悬停交互效果。

## 布局方案

在现有的"数据概览"下方、"主题分布+情感分布"上方插入4个新图表，采用2x2网格布局：

- 左上：面积分布直方图
- 右上：面积-主题堆叠柱状图
- 左下：面积三元图
- 右下：面积-尺寸相关性分析

## 交互设计

- 鼠标悬停显示详细数据
- 图表支持缩放和平移（三元图除外）
- 点击图例可以切换系列显示
