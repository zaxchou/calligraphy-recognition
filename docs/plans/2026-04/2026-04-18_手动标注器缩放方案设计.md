## 需求概述

为 InscriptionAnnotator.vue（手动标注器）添加**滚轮缩放+拖拽平移**功能，用于处理过宽或过长的卷轴图片，要求：

1. 滚轮缩放（支持 10%-1000%）
2. 拖拽平移（空格键+拖拽或中键拖拽）
3. 坐标必须精准（保存的是原始图片坐标）
4. 可自行测试验证

## 技术方案

### 核心原理

使用 **SVG viewBox 缩放**（而非 CSS transform），因为：

1. viewBox 是 SVG 原生缩放机制，不影响坐标系统
2. `getScreenCTM()` 自动适配 viewBox 变化，坐标转换无需额外处理
3. 所有顶点坐标保持原图坐标系（0,0)-(width,height)，保存无偏差

### 关键设计

- **缩放状态**：`viewBoxX`, `viewBoxY`, `viewBoxW`, `viewBoxH`
- **viewBox 格式**：`"${viewBoxX} ${viewBoxY} ${viewBoxW} ${viewBoxH}"`
- **初始化**：`viewBoxX=0, viewBoxY=0, viewBoxW=imgNaturalW, viewBoxH=imgNaturalH`
- **滚轮缩放**：以鼠标为中心，通过调整 viewBoxW/viewBoxH 实现缩放
- **拖拽平移**：通过调整 viewBoxX/viewBoxY 实现平移
- **SVG 渲染**：`:viewBox="\`\${viewBoxX} \${viewBoxY} \${viewBoxW} \${viewBoxH}\`"`

### 实现步骤

1. 添加缩放状态变量
2. 工具栏添加缩放控制（+/-/重置 + 比例显示）
3. 实现滚轮缩放（以鼠标为中心）
4. 实现拖拽平移（空格+拖拽/中键）
5. 完整自测验证

## 交互设计

### 工具栏

- 新增缩放控制区：`-` `100%` `+` `重置`
- 显示当前缩放比例

### 操作方式

- **滚轮缩放**：鼠标悬停在图片上，滚轮向上放大，向下缩小
- **拖拽平移**：按住空格键 + 拖拽，或者中键拖拽，移动视图
- **重置视图**：点击"重置"按钮，恢复原始大小和位置
