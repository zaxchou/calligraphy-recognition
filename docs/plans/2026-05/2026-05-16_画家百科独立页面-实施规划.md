# 画家百科独立页面 — 实施规划

## 一、概要

将当前的「作者信息」管理 tab（/admin?tab=artist-info）升级为完整的画家百科系统，包含：
- **公开画家百科**：面向所有用户的独立页面，含列表页 + 详情页（多子页面）
- **管理后台**：升级 ArtistInfoManager tab，保留与后台融合（重写为完整编辑功能）
- **前后端共用同一套 API**

## 三、数据库变更

### 3.1 artists 表扩展

```sql
ALTER TABLE artists ADD COLUMN alias TEXT DEFAULT '';          -- 字号（如：字渭川）
ALTER TABLE artists ADD COLUMN dynasty TEXT DEFAULT '';        -- 朝代（清/近现代）
ALTER TABLE artists ADD COLUMN hometown TEXT DEFAULT '';       -- 籍贯
ALTER TABLE artists ADD COLUMN avatar_url TEXT DEFAULT '';     -- 头像URL
ALTER TABLE artists ADD COLUMN death_year INTEGER;             -- 卒年
ALTER TABLE artists ADD COLUMN biography TEXT DEFAULT '';      -- 生平简介（长文本）
ALTER TABLE artists ADD COLUMN bio_events TEXT DEFAULT '[]';   -- 生平时间线 JSON
ALTER TABLE artists ADD COLUMN art_school TEXT DEFAULT '';     -- 画派（多个用逗号分隔）
ALTER TABLE artists ADD COLUMN masterpieces TEXT DEFAULT '[]'; -- 代表作 JSON
ALTER TABLE artists ADD COLUMN tags TEXT DEFAULT '[]';         -- 标签
ALTER TABLE artists ADD COLUMN baidu_url TEXT DEFAULT '';      -- 百度百科URL
ALTER TABLE artists ADD COLUMN view_count INTEGER DEFAULT 0;   -- 浏览量
ALTER TABLE artists ADD COLUMN featured INTEGER DEFAULT 0;     -- 推荐标记：1推荐/0非推荐
```

**bio_events JSON：**
```json
[
  {"year": 1844, "type": "birth", "title": "出生", "desc": "生于湖南湘潭"},
  {"year": 1919, "type": "move", "title": "定居北京", "desc": "定居北京，以卖画为生"}
]
```

**masterpieces JSON：**
```json
["蛙声十里出山泉", "墨虾", "祖国万岁"]
```

### 3.2 新增 artwork_artists 表

```sql
CREATE TABLE artwork_artists (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    artwork_id  INTEGER NOT NULL,
    artist_id   INTEGER NOT NULL,
    role        VARCHAR(20) DEFAULT 'author',  -- author(作者)/co_author(合作者)/attributed(传)
    sort_order  INTEGER DEFAULT 0,
    created_at  TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    UNIQUE(artwork_id, artist_id)
);
```

### 3.3 新增 artist_change_requests 表

```sql
CREATE TABLE artist_change_requests (
    id              INTEGER PRIMARY KEY AUTOINCREMENT,
    artist_id       INTEGER NOT NULL,
    request_type    VARCHAR(30) NOT NULL,
    field_name      VARCHAR(100),
    old_value       TEXT,
    new_value       TEXT,
    change_summary  TEXT,
    submitter_id    INTEGER NOT NULL,
    reviewer_id     INTEGER,
    status          VARCHAR(20) DEFAULT 'pending',
    review_comment  TEXT,
    created_at      TIMESTAMP,
    reviewed_at     TIMESTAMP
);
```

### 3.4 新增 art_schools 表

```sql
CREATE TABLE art_schools (
    id          INTEGER PRIMARY KEY AUTOINCREMENT,
    name        TEXT NOT NULL UNIQUE,
    description TEXT DEFAULT '',
    dynasty     TEXT DEFAULT '',
    origin      TEXT DEFAULT '',
    rep_artists TEXT DEFAULT '[]',    -- 代表人物 JSON
    style_features TEXT DEFAULT '[]', -- 风格特征 JSON
    created_at  TIMESTAMP,
    updated_at  TIMESTAMP
);
```

### 3.5 新增 artist_stats_cache 表（事件驱动缓存）

```sql
CREATE TABLE artist_stats_cache (
    artist_id   INTEGER PRIMARY KEY,
    stats_data  TEXT NOT NULL,      -- 完整统计数据 JSON
    updated_at  TIMESTAMP NOT NULL
);
```

## 四、后端 API 变更

### 4.1 artists.py 增强

| 端点 | 方法 | 说明 | 权限 |
|---|---|---|---|
| `GET /artists` | 增强 | 支持 `?dynasty=` `?school=` `?keyword=` `?featured=` `?page=` `?page_size=` `?sort=` | 公开 |
| `GET /artists/{id}` | 增强 | 返回完整字段 + 聚合数据（作品数、统计、关联库） | 公开 |
| `GET /artists/by-name/{name}` | 增强 | 同上 | 公开 |
| `POST /artists` | 增强 | 支持全部新字段 | `content.upload` |
| `PUT /artists/{id}` | 增强 | 支持全部新字段 + bio_events/masterpieces 替换 | editor 或 owner |
| `DELETE /artists/{id}` | 保留 | 不变 | admin |
| `POST /artists/{id}/sync-name` | 保留 | 不变 | editor |
| `POST /artists/{id}/ai-fill` | 增强 | 升级为百度百科抓取 + AI 补充 | editor |
| `GET /artists/{id}/stats` | **新增** | 完整统计数据（含缓存） | 公开 |
| `GET /artists/{id}/works` | **新增** | 作品列表（分页筛选） | 公开 |
| `GET /artists/periods` | **新增** | 朝代列表 | 公开 |
| `GET /artists/schools` | **新增** | 画派列表 | 公开 |

### 4.2 新增 artist_changes.py

| 端点 | 方法 | 说明 |
|---|---|---|
| `POST /artists/{id}/change-requests` | POST | 提交修改建议 |
| `GET /artists/{id}/change-requests` | GET | 某个画家的变更请求列表 |
| `GET /artists/change-requests/my` | GET | 我的提交 |
| `POST /artists/change-requests/{id}/review` | POST | 审核 |

通知类型新增：`artist_cr_pending` / `artist_cr_approved` / `artist_cr_rejected`

### 4.3 新增 artwork_artists.py

| 端点 | 方法 | 说明 |
|---|---|---|
| `GET /artworks/{id}/artists` | GET | 获取作品的所有关联画家 |
| `POST /artworks/{id}/artists` | POST | 添加关联（含角色+排序） |
| `PUT /artworks/{id}/artists/{artist_id}` | PUT | 更新角色/排序 |
| `DELETE /artworks/{id}/artists/{artist_id}` | DELETE | 移除关联 |

### 4.4 统计数据缓存触发器

在以下操作时触发更新目标画家的 stats cache：
- 作品新增/删除时
- 作品分析完成时
- 作品校对状态变化时
- 作品翻译完成时

触发方式：在被调用的 API 末尾调用 `trigger_stats_cache_update(artist_id)`，或将更新逻辑塞入异步队列。

### 5.3 页面规划

#### 5.3.1 画家列表页 `/artists`

- **推荐区**：featured=1 的画家卡片横幅（水平滚动 or 网格）
- **最近加入**：按 created_at 倒序
- **朝代分类区**：唐/宋/元/明/清/近现代分组，每组横向展示
- **筛选**：搜索框 + 朝代下拉 + 画派下拉
- **画家卡片**：头像（占位图）、姓名+字号、朝代/画派标签、作品数、生卒年

#### 5.3.2 画家详情页 `/artist/:name`（默认展示 overview）

页面顶部：
- 头像（大图）、姓名字号、生卒年、朝代画派标签
- 背景简介
- 管理员可见：编辑按钮、AI填充按钮、「我的修改」入口

**自定义导航栏（简约胶囊/下划线）：**
概览 | 作品 | 印章 | 文献 | 分析

#### 5.3.3 概览 `/artist/:name`（默认）

1. **基本信息卡**：姓名、字号、生卒年、籍贯、朝代、画派
2. **生平时间线**：bio_events 渲染为时间轴
3. **代表作**：3-6幅精选作品缩略图（水平滚动），点击跳转作品详情
4. **关联作品库**：该画家的作品库列表
5. **快速统计**：作品总数、已分析数、已校对数

#### 5.3.4 作品 `/artist/:name/works`

缩略图网格（分页，每页20-30幅），点击进入作品详情。

#### 5.3.5 印章 `/artist/:name/seals`

复用现有 seals 表数据，按 artist_name 关联展示。

#### 5.3.6 文献 `/artist/:name/literature`

文献著录列表（复用 literature_reference 表），按作品分组。

#### 5.3.7 分析 `/artist/:name/analysis`

直接复用 ContentAnalysis 页面的后端数据（`/content-analysis/stats?artist=xxx`），前端展示：
- 主题分布图表（饼图/柱状图）
- 情感倾向分析
- 分期统计
- 标签统计

#### 5.3.8 管理后台升级（ArtistInfoManager.vue）

仍作为 `/admin?tab=artist-info` 使用，重写内容：
- 画家列表：增加朝代/画派筛选、搜索
- 编辑弹窗：增加全部新字段（字号、籍贯、朝代、画派、卒年、头像URL、生平时间线表单列表、代表作列表）
- 编辑弹窗增加「高级规则」Tab页：情感基线、主题分布等（原画家规则功能）
- AI填充按钮：升级为「从百度百科抓取」
- 审核管理入口：查看当前画家的变更请求列表

## 七、关键设计决策

### 7.1 多作者关联策略

- `tubi_analyses.artist` 保留原始单一作者名
- `artwork_artists` 作为补充关联，不替代原字段
- 查询时：先查 artwork_artists，无记录则回退到 tubi_analyses.artist
- 展示：多作者时显示「齐白石、李可染 合作」

### 7.2 编辑权限

- `editor`/`admin`/`super_admin` + 作品库 owner → 直接写入 artists 表
- 其他注册用户 → 写入 artist_change_requests → 管理员审核
- 审核通过 → 自动更新 artists 表 + 通知提交者
- 审核驳回 → 保留原因

### 7.3 统计缓存

- 在 artists 表修改、作品新增/删除/分析完成/校对/翻译时触发缓存更新
- 使用 `artist_stats_cache` 表存储完整统计数据 JSON
- stats API 先查缓存，缓存不存在时实时计算

### 7.4 分析数据复用

- 不重新实现分析逻辑
- 直接调用现有 `/content-analysis/stats?artist=xxx` 等端点
- 前端直接展示已有数据分析图表

### 7.5 导航栏修改范围

- 修改首页导航组件（TubiHome.vue 或对应的布局组件）
- 顺序：首页 → 写意知识库 → **艺术家百科** → 题跋分析 → 潘天寿教你构图 → 起承转合 → 大数据分析 → 翰墨行旅
- 首页卡片区新增「艺术家百科」入口
